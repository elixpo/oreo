# doom_icon — Doom game app launcher icon

**Asset name:** `doom_icon`
**Output size:** 200×200 → optimized to 32×32
**Used in:** `apps/doom/manifest.json`
**Theme reference:** See [THEME.md](THEME.md)

Generate: `python pipeline/generate_assets.py oreoOS/doom_icon`
→ `branding/icons/raw/oreoOS/doom_icon.png`, then `python pipeline/asset_optimize.py`

Trademark note: Oreo's own retro-shooter take — no DOOM logo, lettering or id Software
characters; keep it cute, no gore.
